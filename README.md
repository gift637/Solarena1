# SolArena

> Compete. Trade. Win. — Solana-powered meme coin trading arena.

## Deploy to Vercel

### Option 1 — Drag & Drop (no account needed, 30 sec)
1. Unzip the project
2. Go to https://vercel.com/new
3. Drag the `solarena-clean` folder onto the page
4. Click **Deploy**

### Option 2 — Vercel CLI
```bash
npm i -g vercel
cd solarena-clean
vercel
```

### Option 3 — GitHub
1. Push this folder to a GitHub repo
2. Go to https://vercel.com/new → Import repo → Deploy

## Structure
```
solarena-clean/
```
